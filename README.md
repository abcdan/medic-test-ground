# medic-test-ground

A deliberately imperfect Hello World Express app for exercising an AI code reviewer.

## Run it

```sh
npm install
npm start
```

Open <http://localhost:3000>. Other sample endpoints are:

- `GET /hello/:name`
- `POST /shout` with a JSON body such as `{ "message": "hello" }`

Run the happy-path test with `npm test`.
